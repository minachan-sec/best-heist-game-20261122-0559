**VAULTBREAK — The Midnight Vault Job.** A top-down heist game in three levels: slip past
patrolling guards with wall-clipped vision cones and sweeping wall cameras, hide in
shadows, duck behind display cases, throw coins to pull guards off their routes, grab
the loot and reach the getaway van before the alarm meter fills — a full meter trips a
lockdown and every guard hunts you. Guards patrol, grow suspicious, investigate noises,
chase and search; running is fast and loud. Original art, code and synthesized sound —
no assets, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

WASD / arrows to move, Shift to run, click to throw a distraction coin, P to pause,
M to mute. `?shot=start|play|close|end&seed=1` stages the four screenshot scenes.
